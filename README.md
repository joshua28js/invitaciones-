# 💍 Invitaciones de Boda

Pagina para crear invitaciones de boda personalizadas.

### ¿Qué hace?
- Elige plantilla (Clásica, Floral, Moderna, Bosque, Playa)
- Personaliza nombres, fecha, lugar, foto y color
- Cambia la letra de los nombres
- Envía pedido por WhatsApp
- Confirma asistencia por WhatsApp
